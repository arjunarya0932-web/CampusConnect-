# CampusConnect

**Connect. Learn. Grow Together.**

CampusConnect is a college community platform designed to help students connect, share study resources, ask questions, and stay updated with campus activities.

## Live Demo

- **Website:** https://campus-connect-three-alpha.vercel.app/
- **Backend API:** https://campusconnect-3-6i2z.onrender.com

## Features

- **Student Community:** Share posts and interact with other students.
- **Study Resources:** Share notes and useful academic resources.
- **Doubt Discussions:** Ask questions and discuss academic topics.
- **Likes and Comments:** Engage with community posts.
- **Saved Posts:** Save posts for later.
- **Search:** Find relevant content.
- **Notifications:** Stay informed about activity.
- **Student Profiles:** Manage your profile information.
- **Post Management:** Create and delete posts.
